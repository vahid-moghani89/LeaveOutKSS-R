Install + Setup
===============

1) Install LeaveOutKSS from CRAN
--------------------------------

  install.packages("LeaveOutKSS")

CRAN page:
https://cran.r-project.org/web/packages/LeaveOutKSS/index.html

2) Run examples
---------------

Run scripts from the repository root so their relative paths resolve:

  source("examples/01_basic_no_controls.R")

The examples load the package with:

  library(LeaveOutKSS)

3) Data
-------

Column expectations for local example data are in data/README.txt.
